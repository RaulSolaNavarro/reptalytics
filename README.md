# Reptalytics — NYC Restaurant Inspection Analysis

**Live report:** https://raulsolanavarro.github.io/reptalytics/reptalytics_report.html

A Python/Quarto analysis of 160,000+ NYC DOHMH restaurant inspections (2021–2024), exploring violation score trends, borough-level grade differences (ANOVA), closure rates by borough, and the most common health code violations across cuisine categories.

Built by Randi Shimsky-Agosto, Haley Vargas, Victor Murra Schott & Raúl J. Solá Navarro · Baruch College CIS 9650
